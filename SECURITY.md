# Security

## Driver note

This project does **not** require enabling or bypassing security protections for
`meletrixid.sys`. If Windows or antivirus software blocks that driver, do not
weaken system security to run this project.

## Reporting security issues

Please do not post credentials, private logs, packet captures containing private
traffic, or other sensitive information in public GitHub issues.

For ordinary bugs, use a normal issue with sanitized logs. If the project later
adds a private security-reporting channel, this file will be updated.
